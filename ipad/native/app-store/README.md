# Draft App Store metadata

These proposed en-US fields address the empty Review Notes and What's New fields observed for version 1.1 build 34 on October 17, 2026. They have not been uploaded.

- `review-notes.txt` describes existing behavior. It is not submission-ready until the release owner verifies the demo workspace/node, adds exact navigation to its project and session, records the connected node's software version and relay-visibility setting, and adds tested report/block/filter instructions after implementation. Keep credentials in ASC's dedicated fields, outside the repository.
- `whats-new.txt` describes the verified account/support/license additions. Confirm the text against the final binary and update it if safety changes require a replacement build.

Provider logos remain unchanged. Asset-rights evidence, iPad screenshots, device testing and the safety work remain required. Publishing these fields is a separate step after approval; this directory contains no upload automation.
